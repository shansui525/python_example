# 本地 RAG 示例文档

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）先从知识库检索相关段落，再让大模型基于这些段落回答，从而减少胡编，并让回答可追溯到原文。

## 本系统怎么工作？

1. 把文档切成小段（chunk）
2. 用本地嵌入模型把文本变成向量
3. 提问时检索最相似的若干段
4. 把检索结果和问题一起发给 LLM 生成答案

## 适用场景

- 个人笔记 / 项目文档问答
- 制度、手册、FAQ 查询
- 不想把全部材料每次塞进超长上下文

## 注意

- 答案质量取决于文档质量和切分效果
- 嵌入模型首次下载需要网络
- 生成仍依赖你配置的 LLM API（或 Ollama）
