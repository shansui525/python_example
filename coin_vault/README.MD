## 📖 项目简介

CoinVault Pro 是一款专为金银币收藏爱好者设计的**本地化投资管理系统**。它帮助您：

- 📊 **精准核算**每枚藏品的克价成本与投资收益
- 💰 **实时追踪**持仓市值与已实现盈亏
- 📈 **智能分析**资产配置与价格趋势
- 🗂️ **全生命周期管理**从买入到卖出的完整记录

### 核心优势

✅ **离线运行** - 无需网络，数据完全本地存储，隐私安全  
✅ **自动金价** - 集成新浪API，每5分钟自动更新实时金价  
✅ **专业核算** - 区分投资币/纪念币，动态计算市值与溢价率  
✅ **可视化报表** - 月度趋势图、材质分布、盈亏统计一目了然  
✅ **智能提示** - 关键指标悬停显示计算口径，透明清晰

## ✨ 功能特性

### 🎯 藏品管理

- **完整信息记录**
  - 基础信息：名称、材质（金/银/铂/钯）、类型（投资币/纪念币/流通币）
  - 规格参数：重量、成色、面值、直径、发行量
  - 品相认证：评级分数、证书编号、包装状态
  - 自定义标签：支持个性化分类标记

- **智能筛选查询**
  - 按材质、状态、年份、系列多维度筛选
  - 关键词模糊搜索（名称/ID/标签）
  - 双击编辑，快速修改藏品信息

### 💵 交易管理

- **买入录入**
  - 三栏式表单布局，信息清晰分组
  - 自动计算克价与总成本（含费用）
  - 记录购买渠道与备注信息
  - 支持同批次多数量录入

- **卖出录入**
  - 左侧选择持仓藏品，右侧填写出售信息
  - **实时预览盈亏**，决策更明智
  - 自动计算持有天数、年化收益率
  - 一键完成状态变更（在库→已售）

### 📊 克价与成本核算

| 计算项 | 说明 | 公式 |
|:---|:---|:---|
| 买入克价 | 单枚买入单价 ÷ 重量 | `buy_price / weight` |
| 总成本 | 单价×数量 + 费用 | `buy_price × quantity + fee` |
| 卖出克价 | (卖出金额 - 费用) ÷ 重量 | `(sell_price - fee) / weight` |
| 溢价率 | (买入克价 - 基准金价) ÷ 基准金价 | `(gram_price - gold_price) / gold_price` |

### 📈 盈亏分析

- **已实现盈亏** - 已售藏品的实际收益
  - 盈亏金额 = 净销售额 - 总成本
  - 盈亏率 = 盈亏金额 ÷ 总成本 × 100%
  - 年化收益率 = (盈亏率 ÷ 持有天数) × 365
  - **颜色标识**：🔴 红色表示盈利，🟢 绿色表示亏损

- **未实现盈亏** - 在库藏品的浮动盈亏
  - 投资币：按实时金价动态计算市值
  - 纪念币：优先使用手动估值，否则按成本价

### 🎨 数据可视化

#### 仪表盘
- **5大核心指标卡片**（悬停显示计算口径）
  - 💰 持仓市值：Σ(在库藏品数量 × 当前市场价格)
  - 💵 总成本：Σ(在库藏品买入价 + 买入费用)
  - 📈 已实现盈亏：Σ(已售藏品净销售额 - 总成本)
  - ⚖️ 金币克重：Σ(在库金币的重量)
  - 🎯 金币在库数量：COUNT(材质="金" AND 状态="在库")
- 持仓材质分布表（含数量、成本、市值、平均克价）
- 最近30条交易记录速览

#### 统计报表
- **月度趋势图** - 双轴图表展示月末持仓市值（柱状）+ 当月实现利润（折线）
- **投资收益汇总表** - 按材质分类的已实现/未实现盈亏明细
- **持仓材质分布** - 各材质的数量、克重、成本、市值、在库盈亏对比
- **底部汇总卡片**（悬停显示计算口径）
  - 累计投入：历史总投资金额
  - 持仓成本：当前在库藏品总成本
  - 持仓市值：当前在库藏品总市值
  - 已实现盈亏：已售藏品累计盈亏（🔴红=盈利，🟢绿=亏损）

### 🌐 实时金价监控

- **自动更新** - 接入新浪贵金属API，每5分钟刷新一次
- **多品种支持** - 黄金Au(T+D)、白银Ag(T+D)、铂金、钯金
- **底部状态栏** - 全局显示最新金价与更新时间
- **手动刷新** - 系统设置中可立即获取最新价格
- **历史金价管理** - 支持手动录入或修正历史日期金价

### 💾 数据管理

- **导入导出**
  - 支持CSV/Excel格式批量导入藏品
  - 一键导出全部数据为Excel文件
  - 智能字段映射，兼容多种表格格式

- **备份恢复**
  - 自动保留最近7次数据库备份
  - 支持从备份文件快速恢复
  - 备份文件带时间戳，便于版本管理

- **配置管理**
  - 自定义下拉选项（主题系列、发行机构、购买渠道等）
  - 配置实时同步到录入页面

## 🚀 快速开始

### 环境要求

- Python 3.7 或更高版本
- 支持的操作系统：Windows / macOS / Linux

### 安装步骤

1. **克隆或下载项目**
   ```bash
   cd coin_vault
   ```

2. **安装依赖包**
   ```bash
   pip install tkinter matplotlib requests openpyxl pandas
   ```

3. **启动程序**
   ```bash
   python main.py
   ```

4. **首次使用**
   - 系统会自动创建 `data/coin_vault.db` 数据库文件
   - 日志文件保存在 `log/` 目录下
   - 开始添加您的第一枚藏品！

### 目录结构

```
coin_vault/
├── main.py                 # 主程序入口
├── database.py             # 数据库管理模块

│   ├── __init__.py

│   └── styles.py           # 样式定义

```

## 📚 使用指南

### 1️⃣ 添加藏品

**方式一：通过"买入录入"页面**
1. 点击顶部标签页切换到 **💵 买入录入**
2. 填写必填字段（名称、材质、类型、重量、买入日期、买入单价）
3. 可选填：主题系列、发行年份、评级分数、购买渠道等
4. 点击 **💾 保存记录**

**方式二：通过"藏品库"批量导入**
1. 准备Excel/CSV文件，包含藏品信息
2. 在 **🎯 藏品库** 页面点击 **📥 导入数据**
3. 选择文件，系统自动解析并导入

### 2️⃣ 查看持仓

- 切换到 **📊 仪表盘** 查看总体概况
  - **鼠标悬停指标卡片**可查看详细的计算口径说明
- 切换到 **🎯 藏品库** 查看所有藏品列表
  - 使用顶部筛选器按材质、状态过滤
  - 搜索框输入关键词快速定位
  - 双击任意行编辑藏品信息

### 3️⃣ 记录卖出

1. 切换到 **💴 卖出录入** 页面
2. 左侧列表选择要卖出的藏品
3. 右侧填写：卖出日期、卖出金额、卖出费用、出售渠道
4. 系统自动计算并显示预估盈亏
5. 点击 **💾 确认卖出**

### 4️⃣ 查看报表

- 切换到 **📈 统计报表** 页面
- 右上角选择年份，查看该年度数据
- 图表展示月度持仓与收益趋势
- 表格展示按材质分类的盈亏明细
- **底部汇总卡片**显示累计投入、持仓成本、持仓市值、已实现盈亏
  - **鼠标悬停卡片**可查看详细的计算口径说明
  - **已实现盈亏颜色**：🔴 红色=盈利，🟢 绿色=亏损

### 5️⃣ 系统设置

切换到 **⚙️ 系统设置** 页面：

**📊 金价管理**
- 手动录入历史日期的金、银、铂、钯价格
- 点击"保存金价"记录到数据库

**🌐 API实时价格（新浪）**
- 查看当前实时金价（每5分钟自动更新）
- 点击"🔄 立即刷新"手动获取最新价格

**💾 数据管理**
- **导出全部数据** - 生成Excel备份
- **备份数据库** - 创建当前数据库副本
- **恢复数据库** - 从备份文件还原

## ❓ 常见问题

### Q1: 程序启动后提示缺少模块？
**A:** 请确保已安装所有依赖：
```bash
pip install matplotlib requests openpyxl pandas
```

### Q2: 图表中文显示为方框？
**A:** Matplotlib需要系统中文字体支持。代码已预设常见中文字体：
```python
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Arial Unicode MS']
```
如仍异常，请根据您的操作系统安装对应字体。

### Q3: 如何修改默认的金价更新频率？
**A:** 编辑 `api_gold_price.py` 第98行：
```python
self.update_interval = 300  # 单位：秒，默认300秒=5分钟
```

### Q4: 数据库文件在哪里？可以复制到其他电脑吗？
**A:** 数据库位于 `data/coin_vault.db`，可以直接复制整个 `data/` 文件夹到其他设备，程序会自动识别。

### Q5: 金价API获取失败怎么办？
**A:** 
1. 检查网络连接是否正常
2. 手动在"系统设置"中录入当日金价
3. 查看 `log/` 目录下的日志文件排查具体错误

### Q6: 如何查看指标的计算方法？
**A:** 
- **仪表盘**：将鼠标悬停在任意指标卡片上，等待300毫秒会显示计算口径说明
- **统计报表**：底部汇总卡片同样支持悬停查看计算方法
- 提示内容包括：计算公式、分步计算方法、业务用途说明

### Q7: 已实现盈亏的颜色代表什么？
**A:** 
- 🔴 **红色**：表示盈利（正数）
- 🟢 **绿色**：表示亏损（负数）
- 符合中国股市的习惯，直观易懂
